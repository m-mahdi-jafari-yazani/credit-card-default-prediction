# Credit Card Default Prediction

Predicting whether a credit card client will default on their payment next month.

## Dataset

[Default of Credit Card Clients](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients)
(UCI Machine Learning Repository): 30,000 clients from Taiwan, 23 features and 1 binary target
(`default payment next month`). License: CC BY 4.0.
